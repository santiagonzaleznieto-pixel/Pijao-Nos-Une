# PrecisionGps

Barra de precisión del GPS en «Registrar aquí» (5.3): tres tramos que se encienden a medida que mejora la lectura.

- Siempre con el número y la palabra («±7 m · buena»); los tramos solo refuerzan.
- Débil (más de 20 m) no deja registrar con GPS; se ofrece la ubicación manual con motivo.
- **Lo que pone quien lo usa:** la mejor lectura del muestreo y los umbrales de la configuración (`precision_min_m`).
