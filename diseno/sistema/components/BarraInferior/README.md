# BarraInferior

La barra inferior flotante (18.1): Inicio · Mapa · Registrar aquí · Tareas · Más.

- Flota a 16 px del borde, con `radio-barra`, `superficie-elevada` y `sombra-flotante`.
- La pestaña activa lleva `aria-current="page"`, texto en `tinta` y la pastilla `tinte-azul` que se desliza con `curva-rebote` (450 ms). Las demás, `tinta-suave`.
- El botón central es el `Registrar` naranja: no es una pestaña, abre «Registrar aquí».
- Rótulos de 12 px en Montserrat semibold, siempre visibles (no solo íconos).
- **Lo que pone quien lo usa:** la pestaña activa y la navegación de cada botón.
