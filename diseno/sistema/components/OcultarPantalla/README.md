# OcultarPantalla

«Ocultar pantalla» (5.16): un toque tapa todo con un velo esmerilado y el logo; para volver se confirma con huella o rostro.

- Disponible en la franja superior de toda pantalla con datos de personas y en el menú «Más».
- El velo usa `velo` con desenfoque de 18 px y aparece en 350 ms; el bloque central entra con `pj-entra`.
- **Lo que pone quien lo usa:** la confirmación biométrica al tocar «Volver».
- Nunca muestra datos detrás del velo en capturas: la app ya bloquea las capturas de pantalla.
