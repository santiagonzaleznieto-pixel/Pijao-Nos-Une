# Insignia

Insignias de estado (solo lectura) y chips de filtro (se tocan para prender o apagar).

- Insignia: `pj-insignia` con el par `tinte-*` / `texto-*` y un ícono cuando el estado importa (✓ completo, ! por revisar, × no contactar).
- Chip de filtro: `pj-chip`, 40 px de alto (zona táctil de 48 con su separación), `aria-pressed` dice si está prendido; prendido se rellena de `accion-secundaria`.
- **Lo que pone quien lo usa:** el texto (una o dos palabras) y, en los chips, la acción de filtrar.
