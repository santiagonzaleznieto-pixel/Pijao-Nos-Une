# HojaInferior

Hoja que sube desde abajo (la ficha rápida P-10 al tocar una casa en el mapa, menús de acciones).

- Esquinas de arriba con `radio-barra`, asa visible, `superficie-elevada` y `sombra-flotante`; sube en 600 ms con `curva-suave`.
- Detrás, el `velo`. Se cierra tocando el velo, deslizando hacia abajo o con «Atrás».
- Máximo dos botones; el principal sólido.
- **Lo que pone quien lo usa:** el título, el resumen (solo datos enmascarados) y las acciones.
