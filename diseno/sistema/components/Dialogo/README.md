# Dialogo

Diálogo de confirmación para acciones que no se deshacen (cerrar un teléfono, borrar, «No contactar»).

- Título en pregunta, una explicación de qué pasará y dos botones: «Cancelar» (suave) y la acción con su verbo (peligro). Nunca «Aceptar / Cancelar».
- Aparece con 450 ms de `curva-rebote` sobre el `velo`; `role="alertdialog"` y el foco va a «Cancelar».
- **Lo que pone quien lo usa:** la pregunta, la consecuencia y la acción.
