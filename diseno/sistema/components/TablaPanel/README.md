# TablaPanel

Tabla y filtros del panel web (P-36, P-41, P-43).

- Encabezados en MAYÚSCULAS pequeñas (`tinta-suave` sobre `superficie`), filas de 52 px con divisor `borde` y resaltado suave al pasar el puntero.
- Números con cifras tabulares y alineados; los estados con `Insignia` (ícono + palabra).
- Filtros con `pj-chip` sobre la tabla (uno activo a la vez cuando son excluyentes).
- En pantallas angostas la tabla se desplaza de lado dentro de su caja; la página nunca.
- **Lo que pone quien lo usa:** las columnas, los datos (enmascarados según el rol) y la acción de cada fila.
