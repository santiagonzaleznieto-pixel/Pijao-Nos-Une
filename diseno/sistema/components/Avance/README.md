# Avance

Anillo de avance para zonas y metas (9.2): el porcentaje dentro del anillo y el conteo al lado.

- El anillo se dibuja en 1 s con `curva-suave`; el número del centro y el conteo de al lado dicen lo mismo con palabras.
- Un solo color por anillo (`marca-turquesa` para cobertura); el degradado completo queda para la barra de cobertura.
- **Lo que pone quien lo usa:** el porcentaje ya calculado y su texto alternativo (`aria-label`).
