# Notificacion

Notifications inside the app (the P-20 inbox) and the wording of the phone's notifications.

- Card on `superficie-elevada` with an icon in a tinted square (the tint by type: blue for tasks and announcements, orange for pending items, red for security), a bold title, one line of detail and the time.
- Unread: the border in `marca-azul`. It comes in from above in 350 ms with `curva-suave`.
- **No personal data in any notification** (3.5): never names, ID numbers or addresses of the families visited. «Tiene 1 tarea para hoy», not «Visite a María Fernanda».
- The phone's notification uses a single-color icon (the app's white silhouette) and the same title text.
- **What the consumer provides:** the type (for the icon and tint), the title, the detail, the time and what opens when tapped.
