# Estados

Los cinco estados comunes de toda pantalla (18.1): cargando, vacío, sin señal, error y sin permiso.

- **Cargando:** esqueletos con la forma del contenido real (no un círculo girando); `aria-busy="true"`.
- **Vacío:** ícono, una frase y **una** acción para salir de ahí.
- **Sin señal:** tranquiliza: todo se guarda en el teléfono. Nunca bloquea el trabajo de campo.
- **Error:** qué pasó en palabras simples y «Reintentar».
- **Sin permiso:** qué permiso falta y a quién pedirlo.
- **Lo que pone quien lo usa:** el texto de cada estado según la pantalla y la acción de salida.
