# TarjetaSeccion

Tarjeta de sección con borde (`pj-seccion`) y fila de enlace (`pj-fila-enlace`).

- La sección lleva `borde`, `radio-seccion` y ninguna sombra ni tinte. Encabezado con `pj-etiqueta` (MAYÚSCULAS espaciadas, `tinta-suave`) y, a la derecha, el dato de actualización.
- **Nunca** ponga una tarjeta dentro de otra: dentro de una sección van filas, barras y cifras, sin bordes propios.
- La barra de cobertura es el único lugar con el degradado completo de la marca; se llena con `pj-llena` (1,1 s).
- La fila de enlace va sobre `superficie`, 56 px de alto, con ícono a la izquierda.
- **Lo que pone quien lo usa:** el título, los datos ya agregados y la nota de cómo se cuentan.
