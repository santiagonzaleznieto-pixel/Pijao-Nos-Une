# Logos

- `logo-circular.jpg`: el logo ilustrado (paisaje cafetero, sol, río, carretera y el nombre). Se usa recortado en círculo sobre blanco, con `sombra-logo`: en la entrada, el velo de «Ocultar pantalla», el carnet y los certificados. Nunca más pequeño de 64 px de diámetro.
- `logo-texto.jpg`: el nombre PIJAO NOS UNE en Montserrat con el degradado azul, turquesa, verde y naranja. Para escalar a cualquier tamaño, recrearlo en texto con `.pj-marca-texto`; esta imagen es la referencia.
- Faltan los archivos vectoriales (SVG o PDF) para sacar los colores exactos con cuentagotas (Fase 2.2); los colores de `marca-*` se tomaron de estas imágenes.
